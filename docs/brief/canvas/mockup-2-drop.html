If Brand goes in “By”, this question can be drawn as

  • Share over time best fitEach brand's share, month by month. The largest are drawn and the rest are shown together as All other.
  • Table alwaysThe figures behind the chart, and a file of them.
  • RankingA ranking looks at one window, and this question runs over time. Rank the last 12 months instead
  • GridA grid crosses two fields. Drop a second field on “Across”.
  • DistributionA distribution needs a field whose values run in order, such as a band.
  • MapA map needs a place in “By”.
  • Line over timeLines of a count need “the number” in “Show”. Show the number instead
